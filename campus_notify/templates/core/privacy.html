{% if llm_configured %} 当前使用大模型识别：只有你主动点「开始识别」后，这批文本才会发送给识别服务用于提取字段，不做其他用途。 {% else %} 当前在本机识别：原文不离开本机，识别完全本地完成。 {% endif %}

存什么

  • 原文：默认保存，用于回看原文与字段证据；可随时关闭保存或整批删除。
  • 事项：事件名、时间、地点、链接等结构化字段。
  • 邮箱：用于登录（含邮箱验证码登录）、注册验证以及把提醒发给你，不用于其他用途、不对外提供。
  • 修改记录：你对识别结果的改动，用于持续提升识别准确率，随账号一起删除。
  • 运行日志：只记耗时、条数、失败原因，不留原文副本。

提醒邮件里有什么

到点的提醒会发到你的注册邮箱，内容包括事项名、时间、地点、要求与一个详情页链接， 不包含通知原文全文，也不含其他人发给你以外的任何内容。邮件经学校的邮件服务商投递。

不想收邮件：账号 → 取消「提醒同时发到我的邮箱」， 提醒仍会出现在站内「提醒」页。

不做的事

  • 不读取 QQ / 微信聊天记录，不自动登录教务系统；
  • 不获取通讯录、位置等无关权限；
  • 不投放广告；
  • 不把数据用于识别之外的用途。

怎么删

  • 单条事项：事项详情页「删除」；
  • 只删原文：我的数据 →「删除全部原文」；
  • 清空全部：「我的数据」→「清空全部数据」；
  • 连账号一起删：账号 →「注销」。
